# Code of Conduct

This project follows the Contributor Covenant principles: be respectful,
inclusive, constructive, and security-minded.

## Expected behavior

- Treat contributors with respect.
- Discuss technical trade-offs with evidence.
- Report security concerns privately using `SECURITY.md`.
- Avoid sharing real personal data, secrets, credentials, or production memory
  contents in issues, examples, tests, datasets, or screenshots.

## Unacceptable behavior

- Harassment or discriminatory language.
- Publishing secrets or personal data.
- Encouraging bypasses of consent, tenant isolation, audit, encryption, or
  release gates.

## Enforcement

Maintainers may remove content or contributions that violate this policy and may
block contributors who repeatedly ignore project safety rules.
